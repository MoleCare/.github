# Celebration assets

Animated GIFs the `Celebrate merge` workflow posts when a pull request is
merged. Referenced by URL from every MoleCare repository, so no code repository
has to hold a binary image — see [NOTICE](./NOTICE) for why that matters.

| File | Used when a PR title looks like |
| --- | --- |
| `ship-it.gif` | `feat`, `add`, `new` |
| `nailed-it.gif` | `fix`, `bug`, `hotfix`, `patch` |
| `nice-work.gif` | `doc`, `readme` |
| `high-five.gif` | `test`, `ci` |
| `cleanup.gif` | `refactor`, `clean` |
| `celebration.gif` | anything else |

Raw URL shape:

```
https://raw.githubusercontent.com/MoleCare/.github/main/celebrate/<file>
```
