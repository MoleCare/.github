# Security Policy

This is the default policy for every MoleCare repository that does not have its own
`SECURITY.md`. Thank you for helping to keep MoleCare and the people who use it safe.

## Reporting a vulnerability

**Please do not open a public issue for security problems.**

Email **info@molecare.co.uk** with:

- what the issue is and where it lives
- how to reproduce it
- what an attacker could do with it

If the repository has GitHub private vulnerability reporting turned on, you can use
that instead.

You should get an acknowledgement within **3 working days**. We will tell you when we
have a fix, and we will credit you in the release notes unless you would rather we
did not.

## Scope

- code in MoleCare repositories
- the MoleCare apps and API
- dependency vulnerabilities that the code can actually reach

If a repository has its own `SECURITY.md`, that one applies.

## Personal data

Never put real health data, real skin photos or real credentials in a report or an
issue. Please use made-up data.

MoleCare is not a medical device.
